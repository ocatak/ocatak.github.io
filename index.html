Ferhat Ozgur Catak

Professor of Cyber Security · University of Stavanger, Norway

Ferhat Ozgur Catak is a Professor of Cyber Security at the University of Stavanger (UiS), Norway. His work covers how real systems are attacked and how to keep them secure, in three areas: penetration testing and malware analysis, quantum technologies for security, and trustworthy AI.

He teaches ethical hacking and software security at UiS. Before joining UiS in 2021 he worked on cryptography and malware analysis at TÜBİTAK BİLGEM in Türkiye, and on AI reliability and data privacy at NTNU and Simula Research Laboratory in Norway. He created the public Mal-API-2019 malware dataset and the QuantumUQ library for quantum machine learning.

Research areas

Penetration testing and malware analysis

Traditional, hands-on cyber security: finding vulnerabilities before attackers do, and understanding how malicious software behaves so it can be detected.

Ethical hacking · web application security · malware datasets · behavioural malware detection · intrusion and DDoS detection

Selected work

Mal-API-2019: Windows malware API-call dataset

A public benchmark of Windows PE malware behaviour recorded in Cuckoo Sandbox, covering eight malware families. Widely used as a benchmark in malware-classification research. Paper: PeerJ Computer Science, 2020.

QuantumUQ: uncertainty quantification for quantum machine learning

An open-source Python library for Qiskit and PennyLane, listed in the IBM Qiskit ecosystem. PyPI · Documentation · Paper

Trustworthy AI: From Theory to Practice (book, 2024)

With Murat Kuzlu. A practical guide to building AI systems that are robust, explainable and secure, with companion code. Open access · Amazon · Code

Quantum statistical learning theory: concepts, regimes, and open problems

A single-author overview of what can be learned from quantum data with finite measurements. Quantum Information Processing, 2026.
