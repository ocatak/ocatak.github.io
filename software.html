Research software and datasets

Ferhat Ozgur Catak created the public Mal-API-2019 Windows malware dataset and QuantumUQ, an open-source Python library for uncertainty quantification in quantum machine learning listed in the IBM Qiskit ecosystem. I publish code and data with my papers so that results can be reproduced and built on. Everything is on GitHub.

Penetration testing and malware analysis

Research context: Penetration testing and malware analysis.

ProjectDescription
Mal-API-2019 (malware_api_class)Dataset. Windows PE malware API-call sequences from Cuckoo Sandbox, eight malware families. Cite: PeerJ CS 2020.
