Quantum technologies for security

Quantum technologies change security in two ways. They threaten today's public-key cryptography, and they offer new tools such as quantum key distribution and quantum machine learning. My work asks when quantum learning can be trusted, using learning theory and uncertainty quantification, and how quantum technologies can make systems more secure.

Focus

  • Quantum learning theory. Generalisation guarantees when a model sees only a finite number of measurement shots, how to allocate a measurement budget, and how much incompatible measurements increase the number of state copies needed for learning.
  • Reliable and trustworthy quantum machine learning. Uncertainty quantification, calibration and adversarial robustness of quantum models on noisy (NISQ) hardware.
  • Quantum-secured communication. Quantum key distribution (QKD) to protect federated learning for 6G physical-layer tasks such as channel estimation.
  • Post-quantum cryptography. Migration to post-quantum algorithms such as ML-KEM, and crypto-agility for existing systems.

Research software

QuantumUQ is an open-source Python library for uncertainty quantification in quantum machine learning (Qiskit and PennyLane), written by Ferhat Ozgur Catak and listed in the IBM Qiskit ecosystem.

  • QuantumUQ: uncertainty quantification, calibration and reliability benchmarking for quantum machine learning with Qiskit and PennyLane. Listed in the IBM Qiskit ecosystem. PyPI · Documentation
  • quantum-measurement-budget-allocation: code and experiments for the finite-shot generalisation bound and the measurement-budget allocation rule.
  • quantum-learning-copy-cost: reproducible experiments on minimax bounds for learning from incompatible observables (work in progress).
  • qkd-fl-wireless-security: QKD-secured federated learning for channel estimation in 6G.
  • trustworthy-quantum-machine-learning: a framework for uncertainty, adversarial robustness and federated privacy in quantum machine learning.
